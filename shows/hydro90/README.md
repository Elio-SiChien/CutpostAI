# 示范节目：Hydro90会客室

一套真实在用的节目配置，可以直接用，也可以照着做你自己的节目。

| 文件 | 作用 |
|---|---|
| `show.json` | 节目名、三个栏目（全球科研文化大图鉴 / 就业系列 / AI系列）和各自的固定导语、标题格式 |
| `template/base.html` | 推文的固定部分（头图、平台介绍、分隔线、二维码）+ 占位标记 |
| `template/fragments/` | 会重复的小块：嘉宾照片、嘉宾卡片、章节行、正文段落… |
| `tools/extract_wechat_template.py` | 当初从已发布的 EP31 推文自动拆出模板的脚本（针对秀米版式） |
| `examples/示例_科研文化系列/` | 科研文化系列示例（内容虚构） |
| `examples/示例_就业系列/` | 就业系列示例（内容虚构；期号故意留空，演示“没填期号会提示”） |

示例里的嘉宾、主持人、联系方式都是虚构的，不含任何真实个人信息。

## 照着做自己的节目
1. 复制整个 `hydro90` 文件夹，改名（比如 `myshow`），放在 `shows/` 下或任何地方
2. 改 `show.json`：节目名、栏目、导语
3. 换模板：在 Claude Code / Codex 里 @ 你已发布的一篇推文（浏览器插件 SingleFile 保存的 .html），说「按 cutpost 的 docs/make-a-template.md 把它做成 myshow 的模板」
4. 放在 `shows/` 下的节目直接可用；放在别处就说「把这个文件夹登记成我的节目」
